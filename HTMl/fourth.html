Form

HTML forms are essential for collecting user input and sending it to a server for processing. They are created using the form element, which acts as a container for various input elements like text fields, checkboxes, radio buttons,and submit buttons.

  • Form is define by using "form..../form" tag
  • The action attribute in an HTML form element specifies the URL where the form data should be sent when the form is submitted.
  • It contain various tag like input, label, select and option etc.

Attributes are used to add more information to tag.

1. Heading Tag- used to display heading in HTML. There are 6 heading i.e; h1,h2,h3,h4,h5,h6.Heading Tags are used to show the important of that content h1 is most important and h6 is lest important.
2. Anchor tag- used to add links to our webpage. "< a herf=""></ a>" <br>
Anchor Tag has two type of link - a. Absoult and relative link.<br>
Absoult link- When our any HTML file or Image is placed in different folder.<br>
Relative link- When any HTML, Image or any other file placed in folder or same directory. <br>
3. Image tag-used to add Images to your page. img tag is used for adding Image in webpage. <br>
Img Tag used "src" attribute to add image. Link may be relative or Absoult.<Br>
Img tag also used "alt" attribute to define there name, it shown in webpage if Image is not Found.<br>Img Tag use many attribute like height,width for adjusting Image size. Best option to use only one of these attribute (either height:mostly use or width).

Bold(b)- used to bold the Text eg:<b>Bold</b><br>

Small(small)- used to big font size text eg:<small>Text</small><br>

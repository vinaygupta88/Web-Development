## 📌 About The Project

This Currency Converter is built using **HTML**, **CSS**, and **JavaScript**. It allows users to convert currencies instantly by fetching the latest exchange rates from an API.

<br>

## ✨ Features

✔️ Real-Time Currency Conversion
✔️ Easy-to-Use Interface
✔️ Responsive Design
✔️ Country Flags Support
✔️ Currency Swap Functionality
✔️ API Integration
✔️ Error Handling
